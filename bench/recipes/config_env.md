# 配方：把硬编码的配置改成从环境变量读

**适用**：「把 X 改成可配置 / 从环境变量读」「去掉写死的 X」这类把常量改成配置的请求
**不适用**：要引入新的配置框架、要改部署脚本的
**前提**：项目有测试命令

## 步骤
1. 找出**所有**用到点，两种搜法都要做：
   - 按名字搜：`grep -rn -i '<配置名>' <源码目录>`
   - 按旧值搜：`grep -rnE '\b<旧值>\b' <源码目录>` —— 写死成字面量的地方按名字搜不到（注释里写着的也要看一眼是不是在描述它）
   列一张表：文件:行号 → 现在怎么用
2. 集中在一个地方读取（已有配置模块就放那里）：读环境变量、给默认值、不合法时抛出明确的错误；其它地方一律引用它，不再各自写数字
3. 逐个改第 1 步表里的位置
4. 补测试：默认值、环境变量覆盖、非法值报错，三种都要有；如果配置在模块导入时读取，测试里要重新加载模块
5. 跑全部测试
6. 再执行一次第 1 步的「按旧值搜」，确认源码里不再有写死的旧值

**成功判据**：全部测试通过，且第 6 步没有残留
**失败时**：测试失败 → 看报错改，最多 3 轮；仍失败 → 停下报告哪些用到点改了、哪些没改

## 不要做
- 不要只改配置模块里那一个常量就认为完成
- 不要为了让测试通过去改原有测试的断言
