# 配方：脏 CSV 清洗后分组汇总

**适用**：「把导出的表按月/按地区汇总」「算各组合计」这类对导出数据做分组求和的请求
**不适用**：要改原始数据、要连数据库的
**前提**：有 Python

## 选路
| 条件 | 走 |
|---|---|
| `python -c "import pandas"` 成功 | 路线 A |
| 没有 pandas | 路线 B（不要临时 pip install） |

## 先体检数据（两条路线都要做，一次脚本做完）
打印：总行数；每列取值的样例和**不同写法**（日期有几种格式、金额带不带货币符号/千分位、分类字段的大小写和空格）；
主键重复数和**整行重复数**。体检结果决定下面的清洗规则，不要凭第一眼猜。

## 路线 A：pandas（默认）
1. 一个脚本完成：读入（全部按字符串读）→ 去整行重复 → 分类字段 `strip()` + 统一大小写 → 金额去掉非数字字符转数值 → 日期按体检出的每种格式分别解析（不要用自动猜格式）→ 过滤条件按统一大小写后比较 → 分组求和 → 按要求的列名和格式写出
2. 核对：输出合计 = 过滤后明细合计；任挑一格用另一种方式（如 grep 原始行手算）复核

**成功判据**：两项核对都对上，且日期解析失败数为 0
**失败时**：有解析不了的值 → 打印出来补规则再跑；其它 → 停下报告

## 路线 B：标准库 csv（备用）
同路线 A，用 `csv.DictReader` + `collections.defaultdict` 实现。

**成功判据**：同路线 A
**失败时**：停下报告

## 不要做
- 不要把整份 CSV 读进对话里看
- 不要让库自动猜日期格式（日/月 和 月/日 会被悄悄搞反）
- 不要跳过重复检查
